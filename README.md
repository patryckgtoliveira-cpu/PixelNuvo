# PixelNuvo

Site institucional da PixelNuvo.

## Publicação no GitHub Pages

O workflow `.github/workflows/deploy-pages.yml` publica o site no GitHub Pages
quando há alterações na branch `main` ou quando a publicação é iniciada
manualmente em **Actions**.

Na primeira publicação, habilite **Settings > Pages > Build and deployment >
Source > GitHub Actions** no repositório. Depois que o workflow terminar com
sucesso, o endereço será:

https://patryckgtoliveira-cpu.github.io/PixelNuvo/
